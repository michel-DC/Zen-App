# Product

<!-- impeccable:product-schema 1 -->

## Platform

adaptive

## Users

Une seule personne : le propriétaire de ce PC Windows, qui transforme ponctuellement des fichiers sans les envoyer vers un service externe.

## Product Purpose

Zen réunit des transformations documentaires et d’images dans une application locale. La réussite est de choisir un outil, sélectionner un fichier, régler uniquement les options utiles et retrouver le résultat au bon emplacement.

## Positioning

Une boîte à outils personnelle Windows qui traite les fichiers sur la machine de l’utilisateur, sans compte, serveur ni téléversement.

## Operating Context

Usage sur un PC Windows, dans une fenêtre de bureau. LibreOffice est utilisé localement pour les transformations DOCX/PDF. Les opérations portent sur des PDF, DOCX, PNG et JPG.

## Capabilities and Constraints

Conversions DOCX/PDF, PNG/JPG, images vers PDF, extraction de texte depuis PDF/DOCX, OCR d’images, rognage, coins arrondis et image circulaire. L’application doit utiliser exclusivement les conventions et les contrôles d’une application Windows native ; elle ne doit jamais prendre l’apparence d’un site web. L’OCR dépend d’un moteur local lorsqu’il est disponible.

## Brand Commitments

Nom : Zen. Ton direct, utile et discret. Respect de la confidentialité locale.

- La tâche prime sur la décoration.
- Les actions, les formats et les résultats doivent être explicites.
- Les réglages apparaissent seulement lorsqu’ils sont nécessaires.
- L’interface respecte les conventions Windows connues.
